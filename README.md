# Python Web Server

This is a simple Python web server that serves static files in the current directory.

## Installation

1. Clone the repository:
```
git clone https://github.com/username/python-web-server.git
```

2. Navigate to the project directory:
```
cd python-web-server
```

3. Install the required dependencies:
```
pip install -r requirements.txt
```

## Usage

1. Start the web server by running the following command:
```
python server.py
```

2. Open your web browser and navigate to `http://localhost:8000` to view the files in the current directory.

3. To stop the web server, press `Ctrl + C` in the terminal.

## Configuration

You can configure the web server by modifying the `server.py` file. You can change the port number, directory to serve files from, and other settings as needed.
