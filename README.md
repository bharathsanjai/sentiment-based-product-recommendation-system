# Python Web Server

This is a simple Python web server that can be used to serve static files or dynamic content.

## Installation

1. Clone the repository:

```
git clone https://github.com/yourusername/python-web-server.git
```

2. Install the required dependencies:

```
pip install -r requirements.txt
```

## Usage

1. Start the server by running the following command:

```
python server.py
```

2. Open your web browser and go to `http://localhost:8000` to access the web server.

## Configuration

You can modify the `server.py` file to change the port number or add custom routes for dynamic content.
