# Python Web Server

This is a simple Python web server that can be used to serve static files or handle dynamic requests.

## Installation

1. Clone the repository:

```
git clone https://github.com/yourusername/python-web-server.git
```

2. Install the required dependencies:

```
pip install -r requirements.txt
```

## Usage

1. Run the server:

```
python server.py
```

2. Open your web browser and navigate to `http://localhost:8000` to see the server in action.

## Configuration

You can configure the server by modifying the `config.py` file. Here you can change the port number, set the server root directory, and add custom routes.
