# Python Web Server

This is a simple Python web server that can be used to serve static content or handle HTTP requests. It is built using the `http.server` module that is included in Python's standard library.

## Usage

1. Clone this repository:

```bash
git clone https://github.com/your-username/python-web-server.git
```

2. Navigate to the project directory:

```bash
cd python-web-server
```

3. Start the web server:

```bash
python server.py
```

By default, the server will listen on port 8000. You can access the server by opening a web browser and navigating to `http://localhost:8000`.

## Customization

You can customize the server by editing the `server.py` file. You can change the port number or add additional functionality to handle different types of HTTP requests.
