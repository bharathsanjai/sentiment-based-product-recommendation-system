# Python Web Server

This is a simple Python web server that serves static files from a specified directory.

## Installation

1. Clone the repository:

```
git clone https://github.com/yourusername/python-web-server.git
```

2. Install the required dependencies:

```
pip install -r requirements.txt
```

## Usage

1. Start the web server by running the following command:

```
python server.py
```

2. Open a web browser and navigate to [http://localhost:8000](http://localhost:8000) to view the server.

3. Place your static files in the `static` directory to serve them from the web server.

## Configuration

You can configure the web server by modifying the `config.py` file. Here you can specify the port number, the directory to serve files from, and other settings.
