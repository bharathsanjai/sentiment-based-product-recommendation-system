# Python Web Server

This is a simple Python web server that serves static files in the current directory. It uses the `http.server` module from Python's standard library.

## Prerequisites

- Python 3.x

## Usage

1. Clone the repository: `git clone https://github.com/your-username/python-web-server.git`
2. Navigate to the directory: `cd python-web-server`
3. Run the server: `python server.py`
4. Open your web browser and go to `http://localhost:8000`

## Customization

You can customize the port number by editing the `server.py` file. Simply change the `PORT` variable to your desired port number.
